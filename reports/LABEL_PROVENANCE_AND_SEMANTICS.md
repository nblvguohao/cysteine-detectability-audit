# 标签溯源：这批阳性到底是什么

日期：2026-09-13。这是第 0 阶段那项"标签溯源"的结果。**结论会改变论文题目。**

## 一句话

本项目 15,215 个训练阳性的证据层级是"该半胱氨酸在一次持硫化富集流程中被拉下来并被烷基化"，**不是"该半胱氨酸被持硫化"**。前者是蛋白层面富集加位点层面观察，后者需要谱图里带完整加合物。

## 证据

### 字段本身

`inputs/site_evidence_index.csv` 共 17,178 行，`evidence_scope` 无一例外是 `capture_workflow_CAM_candidate_not_direct_plusS`。字段结构（`collapse_keys` 形如 `A0A060KY90_C318_M1`、`multiplicities` 取值 1–4、`protein_groups` 分号分隔）是 MaxQuant 位点表的形态。`max_site_probability` 在 17,178 行里有 17,176 行等于 1——真实的可变修饰定位概率分布不会是一个常数，这本身就说明该字段在此导出中没有分辨率，项目此前也已记录过这一点。

### 化学含义

tag-switch 与 dimedone switch 的流程是：先用 MSBT、NBF-Cl、MMTS 或 IAM 封闭游离巯基，再让持硫化的 sulfane sulfur 与第二试剂（CN-biotin、DCP-Bio1）反应。**选择性完全落在第二试剂上，而亲和纯化是蛋白层面的**；洗脱后的肽段走常规 DTT/碘乙酰胺处理，所以回收到的 Cys 带的是普通碳酰甲基（+57.021）。这个质量只能说明"这个半胱氨酸被拉下来并烷基化了"，sulfane sulfur 已经被消耗或丢失。

直接证据必须是谱图里的完整加合物：Sulfide（+31.972，Cys-SSH）、CAM-Sulfide 即 S-S-CAM（+57.021+31.972），或位点上的 CN-biotin / DCP 偶联物。方法学依据：Mustafa 2009 建立 MMTS biotin switch（doi 10.1126/scisignal.2000464）；**Pan 与 Carroll 2013 明确指出该化学并不区分巯基与持硫化**（doi 10.1021/cb4001052）；Zhang 与 Xian 2013 tag-switch（doi 10.1002/anie.201305876）；Dóka 2016 ProPerDP（doi 10.1126/sciadv.1500968）；Zivanovic 2019 dimedone switch（doi 10.1016/j.cmet.2019.10.007）。真正为位点级持硫化设计的是 Fu 等 2019 的低 pH QTRP（doi 10.1089/ars.2019.7777，1,547 个位点／994 个蛋白）。

公开沉积里有一个正对应：**PXD061767**（拟南芥重组蛋白）在 Mascot 检索中同时设了 CAM(C)、**CAM-Sulfide S-S-CAM(C)** 与 Sulfide(C) 三个通道。本项目的阳性对应第一个，不是后两个。

### 31% 阳性率从哪里来

这是最直接的算术证据，已在本机复核：

| 量 | 数值 |
|---|---:|
| `inputs/sly_proteome.tsv` 蛋白数 | 34,663 |
| 该蛋白组全部 Cys | 234,881 |
| 证据索引行数 | 17,178 |
| 证据索引涉及的 accession | 5,700 |
| 能映射到该蛋白组的蛋白 | 5,540 |
| 这些蛋白携带的 Cys | 60,905 |
| 映射成功的注释位点 | 16,696 |
| **注释位点 / 注释蛋白内 Cys** | **27.4%** |
| **注释位点 / 全蛋白组 Cys** | **7.1%** |

冻结队列的 31% 正是这样来的：分母被限制在"被检测到的蛋白"之内。没有任何番茄数据集报告过全蛋白组 30% 的半胱氨酸发生某种 PTM，Aroca 等自己的表述是蛋白层面"至少 5% 的蛋白组"。**一个只在检测到的蛋白内才成立的高阳性率，是"半胱氨酸在实验中被观察到"的签名，而不是"半胱氨酸被持硫化"的签名。** 这与可测性消融的结论完全一致，也解释了为什么 25 个消化特征就能拿到 AUC 0.8192。

## 后果

**必须改的表述**：不能称本模型为 persulfidation site predictor。可辩护的说法是"持硫化富集流程中的半胱氨酸可观测性排序器"，或更保守的"方法依赖注释排序器"，后者项目一直在用。

**仍然站得住的部分**：人 PXD044043 与水稻 PXD072089 是真正的位点级持硫化数据（阳性由单 Cys 肽段推出），模型在它们上的迁移结果不受本节影响，只是要重新表述为"在富集流程中学到的可观测性排序，迁移到了两套真实持硫化数据的观察位点上"。

**仍然缺的一步**：拿到源数据本身，确认行数与位点数对得上，并检查源表里是否存在直接 +S 证据的子集。两个最可能的来源是 doi 10.1111/nph.19188 的 Dataset S1 与 doi 10.1093/plphys/kiae271 的 Supplementary Data Set 1，两者都在付费墙后，需要用机构权限下载。若源表确有 Sulfide 或 S-S-CAM 通道的子集，应在该子集上重跑冻结五折，并把结果作为主结论。

## 边界

本节的化学解释建立在 `evidence_scope` 字段的字面含义与上述方法学文献之上，**尚未与源出版物的补充材料逐行核对**。在核对完成前，这一节应被当作"高置信度推断"，而不是已确认的事实。
