## 一、同源组件：为什么是"替代方案"而不是"复刻"

v3 方案第三节要求外层折按**同源组件**而不是按蛋白分组，理由是旁系同源会跨折。
冻结番茄队列确实有这样一套分组（`inputs/frozen_benchmark_data.npz` 里 4,986 个蛋白收敛为
3,554 个组件，组件以代表登录号命名），但**产生它的工具与阈值在本树里没有任何记录**——
`scripts/common.py` 只消费 `components` 列，不构造它。所以无法复刻，只能自己声明一套，
并在这里明说它是替代而不是同一个程序。

**运行前写定的构造**（全部写在脚本文档字符串里）：

- 比较单位：每条规范序列的 **7 残基 k-mer 集合**；
- 候选对预筛：出现在超过 50 个队列蛋白里的 k-mer 视为无信息、跳过（本次只跳过 8 个）——
  这只用于找候选对，不进入相似度本身；
- 连边规则：较小 k-mer 集合在较大集合中的**含量** `|A∩B| / min(|A|,|B|) ≥ 0.40`；
- 组件 = 该图的连通分量，以其中字典序最小的登录号命名；
- 敏感性阈值 0.30 与 0.50 在同一次运行里一并算出并报在旁边，**所以阈值是可见的而不是事后调的**。

**范围**：本树所有人源分析用到的登录号并集——QTRP 队列、映射后的 qPerS-SID 位点、
PXD044043 持硫化组、ABPP 反应性表。请求 6,801 个登录号，规范蛋白组里有 6,574 个，
缺 227 个（多为 `A0A024...` 一类的旧 TrEMBL 号，无组件，任何分组折都必须排除它们）。
一套分组服务全部队列，后面的人源轮次不用各自再造一套。

肌动蛋白/POTE、β 与 α 微管蛋白、HSPA70、HSP90、ARF、RAS、GNAI——都是教科书级的旁系族，
说明这个免比对替代物抓到的是同源而不是噪声。

**对 QTRP 队列的实际影响很小**：3,614 个蛋白收敛为 3,548 个组件，其中只有 56 个是多蛋白组件。
也就是说按组件分组相对按蛋白分组只多隔离了几十个族，**但这几十个族正是最可能跨折的那部分**。

**边界**（记在审计 `limits`）：免比对含量是序列相似度聚类的替代物而不是比对；短蛋白 k-mer 少、更难连边；
共享结构域可能把并非全长同源的两个蛋白连起来；番茄那套分组由未记录的上游程序产生，
**因此番茄与人源的分组不可直接比较**。

## 二、预注册方案定了什么

完整内容见 json，这里只列会约束后续每一步的条目。

**队列**：主口径 `v3_pooled_ph5_raw`（阴性 = 该臂检出游离巯基且**该臂**未检出持硫化形式，
**保留**在其它臂被标 SSH 的位点——这正是它与被降级的 `arm_clean` 的区别）；
`armclean` 与 `fullclean` 作敏感性；pH 7.6 臂与 S3/S4/S5 只用于排除阴性，不进训练集。

**设计**七个：struct53、chem1046、struct53+chem1046、struct53+零样本分数、
探针 25 维消化、探针 10 维纯可见性，加一个**只作参照的深度列**。
明确不做 ESM-2 微调与 ProtBERT 成员（314 个阳性，上一轮 ESM-2 要 18,458 个位点才压住 53 维）。

**折**：外层按同源组件五折、一次冻结；内层同样按组件五折，用于超参、特征块开关、
Platt 校准、类不平衡（只允许 `scale_pos_weight` 一种口径）与降维（全维 / 互信息前 k ∈ {64,128,256} / 特征族聚合）。
外层测试折不参与预处理统计量、超参、轮数、校准、开关、降维中的任何一项——逐项列在 json 里。
**组件内置换标签的泄漏对照是必跑项**（v2 那次蛋白内置换后是 0.4992，真实 0.8605）。

**主估计量**：深度分层一致性，层为精确检出深度（按**臂**计数）。
json 里专门写了一条 `counting_unit_warning`：深度绝不能按行计数，因为每个持硫化位点都同时被检出为
游离巯基，行计数会编码标签——被丢弃的第一版就是这样读到 0.9478 的。
只含一类的层剔除，剔除量必须写进报告正文。
**全局与组内两个口径都要报**，组内单位是**同源组件而不是蛋白**——理由写在 json 里：
两个口径可以符号分歧（`v2 化学 − 纯可见性` 蛋白内 −0.0414、全局 +0.0307），
而人源 QTRP 队列的蛋白冗余度撑不起蛋白口径（与深度交叉后只剩 18 个蛋白）。

**区间**：同源组件聚类自助 5,000 次、种子 20260915、每次重抽重算统计量。阅读规则沿用三分法。

**预声明差值**六条，包括之前被漏掉的 `v2 化学零样本 − v2 完整零样本`，
并注明它目前只在带 `arm_clean` 机制的合并队列上测过、单臂 raw 未测。

**深度控制**五条：深度不进特征；主指标为分层量；1:2 深度匹配配对子队列（种子写死）；
报分数与深度的 Spearman，**若高于 v2 化学零样本的对应值则即使 AUC 更高也不得部署**；
每一条阴性规则在当主口径前先过共线性前置检查（保留率 → 被消掉协变量的单独判别力 → 再定），
并把两个先例写进 json（`arm_clean` 降级、ABPP 配平不降级）。

**外部验证**按上一轮定案写死：第一层 130 阳性 / 3,974 阴性、**不做深度分层**（协变量只有两个取值）；
第二层两臂、729 阳性 / 1,923 阴性、深度只取 1 与 2、标签必须写成"还原洗脱富集"；
两层不得合并、不得事后择一；外部标签在内部折全部跑完并哈希落盘后**只读一次**；
跨物种缺口（验证全在人源、湿实验做番茄）必须写成未验证。

**部署判据四条全中才换**（分层 AUC 下界 > 0.65；相对 v2 化学零样本的差值下界 > 0；
相对深度列的差值下界 > 0 且分数-深度相关不高于 v2 化学零样本；外部第一层下界 > 0.5）。
任一条不中则 v3 只作方法学结果，**部署权重 0.64/0.20/0.16 不动、锁定预测不重算**。
json 里写明判据在看到任何 v3 数字之后不得修改。
